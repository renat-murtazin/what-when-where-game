# Что? Где? Когда? — Ночь в замке

Полностью локальная игра для Halloween-вечеринки. Работает без интернета, сборки, зависимостей и аккаунтов. Все изображения входят в проект, звуки синтезирует браузер.

## Запуск

Откройте **index.html** двойным щелчком в современном Chrome, Edge, Firefox или Safari. Подключите телевизор по HDMI, включите дублирование экрана и нажмите кнопку полного экрана справа сверху.

Игровой экран помещается в окно без прокрутки. Сверху и снизу оставлены безопасные отступы по 48 пикселей; значения `--tv-top-padding` и `--tv-bottom-padding` можно изменить в `styles.css`. Длинные вопросы автоматически уменьшают размер шрифта по доступному месту, сохраняя весь текст. После изменения размера окна или перехода в полный экран размеры пересчитываются. Списки в окнах настроек и выбора вопросов прокручиваются отдельно от игрового экрана.

На телевизоре счёт расположен вертикально слева от колеса. Расширенная карточка вопроса находится рядом с колесом, таймер — под ней, портрет отправителя — справа. Размер текста уменьшается только при нехватке места, а не по числу символов в вопросе.

Если предпочитаете локальный сервер, из папки проекта выполните:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:8080. Интернет не требуется. Чтобы остановить сервер, нажмите Ctrl+C в терминале.

## Перед вечеринкой

1. Откройте «Настройки». Изначально загружены **15 демонстрационных вопросов**: замените их своими.
2. Вопросы можно добавлять, удалять и перемещать стрелками. Поддерживается от 1 до 200 вопросов, каждый до 6000 символов. Для телевизора лучше использовать короткие вопросы, до 500 символов.
3. Для каждого вопроса можно указать отправителя и путь к фото. Имя вводится в форме после «Вопрос от»: например, «Анны» или «Графини Анны».
4. Можно импортировать JSON-массив строк или объектов с полями `text`, `sender`, `photo`, либо TXT, в котором вопросы разделены пустой строкой. В JSON также принимается объект `{"questions": ["Вопрос 1", "Вопрос 2"]}`. Экспорт JSON сохраняет имена и пути к фото.
5. Установите время раунда и громкость, проверьте звук. Нажмите «Сохранить и вернуться».
6. Сделайте экспорт вопросов как резервную копию. Настройки и прогресс сохраняются в этом браузере автоматически. Хранилище привязано к адресу страницы: file:// и http://, разные порты и разные браузеры не делят данные.

Браузеры требуют щелчок для разрешения звука: нажмите значок динамика или включите эффекты в настройках. Звук по HDMI зависит от выбранного аудиовыхода ноутбука. На телевизоре заранее проверьте громкость.

## Отправители и фотографии

Готовый пример для импорта — [question-setter.example.json](question-setter.example.json). Скопируйте его под своим именем, замените тексты и отправителей, добавьте или удалите элементы списка `questions`. Порядок элементов определяет номера вопросов. Затем откройте **«Настройки» → «Импорт»**, выберите файл, подтвердите замену списка и нажмите **«Сохранить и вернуться»**. Изменённый набор вопросов начнёт новую игру.

В примере первый вопрос использует готовый тестовый портрет, второй ищет фото автоматически по номеру, третий использует имя по умолчанию и автоматический поиск фото с общим портретом в качестве запасного. Поле `text` обязательно; `sender` и `photo` можно оставить пустыми или не указывать. Число вопросов может быть любым от 1 до 200. Используйте обычный JSON без комментариев и запятых после последнего элемента.

Поместите фотографии в папку `senders_img` рядом с `index.html`. Для вопроса № 3 подходят `senders_img/3.jpeg`, `senders_img/3.png` или `senders_img/3.jpg` (именно в таком порядке поиска). Номер — позиция вопроса в настройках. При перестановке вопросов автоматические пути также следуют новой нумерации; чтобы закрепить фото за отправителем, задайте явный путь, например `senders_img/anna.png`.

В поле «Фото» можно оставить пустое значение для автоматического поиска или указать относительный путь к своему JPEG/PNG в папке проекта. Интернет-адреса не используются. Файлы нужно скопировать в проект самостоятельно: редактор сохраняет только путь к ним.

Без имени появится «Вопрос от Тайного гостя». Без найденной фотографии отобразится сгенерированный портрет `senders_img/default.png`. Тестовый портрет графини Анны находится в `senders_img/1.png` и автоматически показывается у вопроса № 1. Замените этот файл своим изображением или удалите, чтобы использовать общий портрет.

Пример JSON с отправителем:

```json
[
  {
    "text": "Текст первого вопроса",
    "sender": "Анны",
    "photo": "senders_img/1.jpeg"
  },
  {
    "text": "Вопрос без указания отправителя"
  }
]
```

Имена и пути к фото можно менять во время игры: такие изменения сохраняют счёт и сыгранные вопросы. Переносите всю папку проекта вместе с изображениями; экспорт JSON не включает сами файлы фото. Ранее сохранённые вопросы без отправителей совместимы с новой версией.

## Игра

- «Вращать колесо» случайно выбирает несыгранный вопрос, показывает его текст и сбрасывает таймер. Выбор без повторов; сыгранные сектора затемняются. При одном вопросе используется всё колесо.
- «Выбрать вопрос» под карточкой открывает список с поиском по номеру, отправителю и тексту. Можно повторно показать сыгранный вопрос без изменения счёта и числа сыгранных вопросов. Впервые открытый вручную вопрос становится сыгранным и больше не выбирается случайно. При выборе таймер сбрасывается, но не запускается автоматически.
- «Начать» запускает обсуждение. Можно приостановить, продолжить, сбросить таймер или изменить длительность от 1 секунды до 99:59.
- Последние 10 секунд звучат сигналы. По окончании звучит гонг и появляется «Время вышло. Ваш ответ?».
- Счёт «Знатоки — Зрители» изменяется кнопками + и −, не опускается ниже нуля. Игра не заканчивается автоматически при определённом счёте.
- Для новой игры откройте настройки → «Сбросить игру» → «Сохранить». Вопросы и длительность сохранятся, счёт и история выбора сбросятся.
- Сохранение изменённого списка вопросов также начинает новую игру; при уже сыгранных вопросах потребуется подтвердить сброс.
- Настройки приостанавливают таймер. После перезагрузки страницы он восстанавливается **на паузе** с учётом прошедшего времени.
- Вопросы и настройки видны на телевизоре при зеркалировании. Подготовьте набор до начала сеанса.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| W / Ц | Вращать колесо |
| Пробел | Старт / пауза (когда фокус не на кнопке) |
| R / К | Сброс таймера |
| F / А | Полный экран |
| M / Ь | Звук |
| Esc | Закрыть окно / выйти из полного экрана |

Клавиши работают вне полей ввода и окон настроек. На сфокусированной кнопке Пробел нажимает эту кнопку, как обычно в браузере. При включённом системном уменьшении движения вращение становится коротким.

## Проверка логики

Требуется только Node.js, без установки пакетов:

```sh
node --test tests/game-core.test.cjs
```

Исходники: `index.html`, `styles.css`, `game-core.js`, `app.js`, `assets/`, `senders_img/`.
