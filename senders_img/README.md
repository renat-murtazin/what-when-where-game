# Фотографии отправителей

Положите фото сюда с номером соответствующего вопроса: `1.jpeg`, `2.png`, `3.jpeg` и т. д. Нумерация начинается с 1 и совпадает с порядком вопросов в настройках. Также поддерживается `.jpg`.

Порядок автоматического поиска: `N.jpeg`, `N.png`, `N.jpg`, затем `default.png`.

В настройках можно задать другое имя файла, например `senders_img/anna.png`. Указывайте относительный путь от корня проекта. После замены файла обновите страницу браузера.

- `default.png` — сгенерированный портрет таинственного отправителя; используется, если персональное фото не найдено.
- `1.png` — сгенерированный тестовый портрет графини Анны для вопроса № 1. Замените своим фото или удалите, чтобы использовать общий портрет. Если добавить `1.jpeg`, он имеет приоритет перед `1.png`.

Имена и пути сохраняются в браузере и при экспорте JSON. Фотографии остаются файлами в этой папке: при переносе игры скопируйте всю папку проекта.
